How authorship is made and named: a meta-aggregator / Wikidata property P742: pseudonym

Wikidata property P742: pseudonym

https://www.wikidata.org/wiki/Property:P742

infrastructureHeteronymy, persona and pseudonymous authorshipAttribution, credit and identity infrastructureactive
The archive's reading. P742 keeps a chosen name on the record, and keeps it as a string attribute of the item about the person who used it, with 'heteronym' listed among the property's own aliases beside pen name and stage name; in #940's terms the data model records a pseudonym (a changed label for one authorial function) and has no place for a heteronym as a distinct function attributable through the civil bearer. A heteronym that has its own Wikidata item would be held elsewhere in the data model; the property page does not show that case.

What its record can settle

  • which names a Wikidata item's subject is recorded as having used under the property pseudonym, with the qualifiers given
  • how Wikidata's data model holds a pen name, stage name or heteronym: as a string value on the bearer's item
  • which subject types and value formats the property permits

What it cannot settle

  • whether a given name is a pseudonym or a heteronym in #940's sense: the property's aliases treat the two as one
  • whether a named authorial function has a corpus, voice or commitments of its own (a string records none)
  • how many items carry the property (not on the saved page)
  • whether any statement is sourced: the page's own statements show '0 references' and the citation constraint is only a suggestion

Kept apart

  • NOT a record of heteronymy as a distinct authorial function: 'heteronym' is an alias of the pseudonym property, and the value is a string
  • NOT an authority file for works: the property attaches a name to a person's item
  • NOT a sourced record by requirement: citation needed is a suggestion constraint
  • NOT a record of the whole Wikidata: the row is about one property of it
  • NOT a count of pseudonyms: the saved page gives none

Relations

  • neighbour: ORCID (Wikipedia's ORCID article (orcid-names--wikipedia) states that Wikidata includes pages with ORCID identifiers; both resolve persons across names)
