The archive's reading. The publisher's page sets the anthology against the claim that text generation began recently and admits only implemented systems, so the record is a lineage of machine output. The archive reads it as a historical map of generated text whose attribution practice (system, programmer, editor) the saved page leaves unrecorded; the anthology itself was not read.

What its record can settle

  • which implemented text generation systems and outputs the editors gather for 1953 to 2023
  • where to find bibliographic references for a given system or output

What it cannot settle

  • how each output is credited (system, programmer, editor), on the saved page
  • whether any example is contemporary LLM co-writing (historical scope alone does not show it)
  • anything from the MIT page, which could not be read

Kept apart

  • NOT a record of contemporary LLM co-writing alone: it spans 1953 to 2023 and includes reports and utilitarian texts
  • NOT a collection of conceptual human–computer collaborations: those are purposefully excluded
  • NOT read in full: the row rests on the publisher's description
